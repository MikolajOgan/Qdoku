# Qdoku

## 4x4 Sudoku Solver via Simulated Quantum Annealing

Constrained Quadratic Model (CQM) -> converting it into a Binary Quadratic Model (BQM / QUBO) -> finding the ground state using OpenJij's Simulated Quantum Annealing (SQA) sampler.
